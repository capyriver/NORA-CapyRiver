NORA 3.18 — Cloudflare Code Mode (Windows x64)

Закрой все старые окна NORA. Распакуй ВЕСЬ архив в новую папку.
Запусти START-NORA.cmd (NORA-3.18.exe), не старый ярлык.
Папка runtime должна остаться рядом с EXE: это Node.js для MCP.
Модели/чаты/настройки в %LOCALAPPDATA%\NORA не удаляются.
Веса моделей не входят в архив и не переобучались.

Исправление по журналу пользователя:
  No such module "cloudflare/pages"
  pages is not defined
Это ошибки кода, предложенного моделью для MCP, а не доказательство плохого входа.

Изменения:
— Для реального Cloudflare Code Mode закреплена инструкция среды:
  search = JavaScript async () => {...}, каталог spec.paths;
  execute = JavaScript async () => {...}, API cloudflare.request(...).
  Эти инструкции больше не выпадают вместе со старыми результатами инструментов.
— Перед задачей публикации исполнитель сам делает ограниченный поиск реальных
  Workers-эндпоинтов через spec.paths. Это чтение API-каталога, не публикация.
  Вызов проходит обычное подтверждение в соответствии с выбранным режимом.
— Поиск/инструкция включаются только при соответствующих реальных tools/list,
  а не для произвольного инструмента с именем execute/search.
— Выдуманный import('cloudflare/pages') / from 'cloudflare/*' / require такого
  SDK отсекается локально до отправки в Cloudflare. Причина видна в чате.
— Успешный каталог повторно используется при восстановлении; неизвестный исход
  записи по-прежнему не повторяется вслепую. Исправления 3.17 сохранены.
— Общая документация Pages не считается доступом к аккаунту или фактом деплоя.
