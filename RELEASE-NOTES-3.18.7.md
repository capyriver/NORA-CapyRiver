# NORA 3.18.7

## English
- Quick-start prompts now follow the selected interface language: English, Russian, or Simplified Chinese.
- Fixed the Write code action inserting Russian text when the interface is set to English.

## Русский
- Быстрые подсказки теперь соответствуют выбранному языку интерфейса: английскому, русскому или китайскому.
- Исправлена кнопка «Написать код»: при английском интерфейсе она больше не вставляет русскую фразу.

## 简体中文
- 快速开始提示现在会跟随所选界面语言：英语、俄语或简体中文。
- 修复了界面设为英语时，“编写代码”操作仍插入俄语文本的问题。
