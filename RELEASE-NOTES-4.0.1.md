# NORA 4.0.1 — Windows x64

## English

- Rebuilt the model picker with distinct CapyRiver 2B and 4B recommendation cards, a stable scrollable model list, and responsive sizing.
- The split-rectangle toolbar icon now opens the shared browser. Removed the separate globe button.
- Reorganized browser tabs, address controls, utility actions, and status into aligned rows; browser side actions no longer overlap or drift.
- Replaced the Sources/Results switcher with a results-only panel. It opens in a compact layout when a new generated file is available.
- Existing conversations and model files remain stored locally across the update.

## Русский

- Переработан каталог моделей: отдельные карточки рекомендаций CapyRiver 2B и 4B, прокручиваемый список и адаптивная высота окна.
- Значок прямоугольника с боковой полосой теперь открывает общий браузер. Отдельная кнопка с глобусом убрана.
- Вкладки браузера, адресная строка, действия и статус размещены в отдельных выровненных строках; элементы управления не наезжают друг на друга.
- Переключатель «Источники / Результаты» заменён панелью только с результатами. Она компактно открывается при появлении нового созданного файла.
- Локальные чаты и файлы моделей сохраняются при обновлении.

## 简体中文

- 重做模型选择器：为 CapyRiver 2B 和 4B 提供独立推荐卡片，模型列表可滚动，窗口尺寸可适配。
- 带侧边栏的矩形图标现在用于打开共享浏览器，并移除了单独的地球图标按钮。
- 浏览器标签、地址栏、工具操作和状态栏分行对齐，避免控件重叠或错位。
- “来源/结果”切换面板已改为仅显示结果；生成新文件时会以紧凑布局自动打开。
- 更新过程中保留本地聊天记录和模型文件。
