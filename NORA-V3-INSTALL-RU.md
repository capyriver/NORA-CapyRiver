# NORA 3.18.1 — подключение собственной NORA AI v3 (4B)

**Статус:** исходники приложения обновлены 4 ноября 2026 года. Проверены целостность оригинального адаптера, Python-тесты и синтаксис интерфейса. **Новый Windows EXE не собран и инференс на RTX 3050 не испытан**: в среде создания архива нет .NET 8 SDK, CUDA и GPU пользователя. Существующий `NORA-3.18.exe` в архиве — **оригинальный, без новой функциональности**. Сборка обязательна.

## Что именно добавлено

- Режим движка `4`: **NORA AI v3 4B**, отдельный от прежних AirLLM, GGUF, LM Studio и Qwen2.5-Coder LoRA.
- Кнопка «Модели → NORA AI v3 4B» и опция в настройках модели. Установка требует отдельного подтверждения.
- Встроенный **оригинальный** адаптер `nora-v3/adapter_model.safetensors` (3 674 728 байт, SHA256: `80120cb91816658e67bc3cbbd7f0d751d217923109cf50f99c656083f00a1139`) и соответствующий `adapter_config.json`.
- Пин базовой модели **`Qwen/Qwen3.5-4B`**, ревизия **`851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a`**. Исходная Qwen3-4B/GGUF *не совместима* с этим адаптером.
- отдельная среда Python `%LOCALAPPDATA%\NORA\nora-v3-runtime`, база `%LOCALAPPDATA%\NORA\nora-v3\base`, инференс через 4-битный bitsandbytes NF4 на NVIDIA CUDA.
- Проверка SHA адаптера, контроль полной загрузки всех шардов базовой модели, офлайн-режим после установки, ограничение контекста 8192 и выхода 2048 токенов, безопасные настройки 4096/512 по умолчанию.
- Загрузка исходной базы только после подтверждения пользователя; чаты, оригинальная модель и существующие настройки при ошибке не удаляются.

## Как получить обновлённый EXE на Windows

1. Распаковать весь архив в **новую** папку. Не заменять текущую папку NORA до проверки.
2. Установить бесплатный .NET SDK 8.0 для Windows x64, если его ещё нет: https://dotnet.microsoft.com/download/dotnet/8.0
3. Запустить `build-windows.cmd` в корне проекта. После успешной сборки запускать `publish\NORA.exe`. Каталог `publish\runtime` должен оставаться рядом с ним.
4. В интерфейсе: **Модели → NORA AI v3 4B**. Подтвердить установку базы. Если приложение попросит, выбрать `python.exe` установленного Python 3.10–3.13 x64.
5. До первого запуска проверить свободное место: **как минимум ~15–20 ГБ** под базовые веса (~9,34 ГБ), пакеты CUDA/PyTorch и временные файлы. Точный объём может отличаться.
6. Нажать «Модели → NORA AI v3 4B» повторно после установки, если нужно выбрать её снова. Настройки по умолчанию: 4096 токенов контекста, 512 токенов ответа, NF4 4 бит, без thinking.

## RTX 3050 8 ГБ VRAM, RAM 16 ГБ

Памяти **должно хватать** для локальной генерации 4B в NF4 при умеренном контексте. Наличие ровно 8 ГБ VRAM обязательно проверить в диспетчере задач Windows. Полный FP16 здесь не рекомендуется. Перед запуском закрой GPU-тяжёлые приложения; если возникнет CUDA out of memory, уменьши контекст до 2048, закрой приложения и повтори. Это **оценка**, не измеренная скорость. CUDA-библиотеки и Torch должны поддерживать драйвер/архитектуру именно твоей RTX 3050. Альтернатива без собственной LoRA: Qwen3.5-4B GGUF, но это уже другая модель.

## Ограничения

- **NORA AI v3 — базовый Qwen3.5-4B плюс собственная LoRA**. Файл адаптера не является полноценным самостоятельным 4B-чекпойнтом и не заменяет базовую модель.
- В этом режиме реализован **только текстовый** запрос. Нативная работа с изображениями не включена, хотя базовая Qwen3.5 мульти-модальна.
- При первой установке требуется интернет; генерация после установки выполняется локально. Диспетчер пакетов `pip` обращается к сети только во время установки.
- Никакое обучение весов в приложении не выполняется.
- Не проверена успешная сборка Windows, CUDA-совместимость установленного PyTorch и реальная генерация текста на ноутбуке: для этого нужен Windows ПК с .NET SDK, Python, NVIDIA-драйвером и GPU.
- Результаты изученного эксперимента на Google Drive (4 ноября 2026): **оригинальная v3 46/57**, повторно обученная копия 45/57, поэтому включён оригинальный адаптер.

## Исходники / проверки

- `src/NoraV3.cs` — интеграция, установка, обработка потоковых событий.
- `src/nora_v3_backend.py` — NF4 + PEFT, проверка оригинала, скачивание проверенной базы, офлайн-ответ.
- `tests/nora_v3_test.py` — проверки адаптера, совпадения базовой модели, целостности шардов, интеграционных строк.
- Тесты: `python -m unittest discover -s tests -p 'nora_v3_test.py' -v`; `python -m py_compile src/nora_v3_backend.py`.
- Для запуска всего набора оригинальных тестов проекта нужны дополнительные Python-пакеты, Playwright и Windows/.NET SDK.

**Проверенные источники**: Google Drive эксперимент `https://drive.google.com/drive/folders/1F_TDq4XSi_z0V-7yG_bzgbIEJILtFptv`, официальный чекпойнт `https://huggingface.co/Qwen/Qwen3.5-4B`.
