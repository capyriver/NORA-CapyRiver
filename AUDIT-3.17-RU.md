# NORA 3.17: короткий цикл MCP

## Установленный дефект
В поставленной 3.16 результат `MCP TOOL FAILED` сохранялся, но не показывался
в UI. Следующий запрос модели не получал постоянную инструкцию исправления.
`Previous()` исключал failed-записи, поэтому тот же запрос отправлялся снова.
На третьем одинаковом предложении `AgentProgress.Accept()` прерывал задачу.
Восстановление сбрасывало счётчик и воспроизводило цикл. Это воспроизведено
тестом production AgentLoop, а не реальным аккаунтом пользователя.

## Изменения
1. Последняя failed-запись сверяется по каноническому ключу перед выполнением
   не-readonly MCP-вызова. Неизменённая ошибка возвращается модели без отправки
   к сервису; исправленные аргументы можно исполнить в том же запуске.
2. Четыре неизменённых предложения после ошибки останавливаются с причиной
   сервиса, без автоматической кнопки resume. Бюджет реальных последовательных
   ошибок MCP: шесть разных попыток. Это ограниченное исправление, не бесконечные
   повторы. Защиты циклов схем, завершённых/неизвестных мутаций сохранены.
3. Последние failed-результаты включаются в checkpoint memo и при восстановлении.
   Транспортное исключение всё ещё оставляет pending: исход неизвестен,
   перед новой записью необходимо проверить состояние сервиса.
4. Видимые `ToolResults`: текстовый блок в чате, ошибки раскрываются автоматически.
   Используется textContent, не HTML. Известные токены маскируются и для старых
   сохранённых результатов. Маскирование не является гарантией удаления всех секретов.
5. Код общего AgentProgress для не-MCP не заменён снятием всех ограничений.

## Границы
Настоящий ответ Cloudflare со скриншота неизвестен: без него нельзя утверждать,
что исправлены его права, API-код или OAuth. Проверены управляемые ошибки
TypeError, SyntaxError, Authentication error и транспортное исключение.
Исправление помогает исполнителю не скрывать причину и не повторять ошибку;
оно не добавляет интеллект/новые веса каждой модели и не гарантирует корректную
публикацию. Windows GUI, реальный Cloudflare и CUDA/Qwen не запускались здесь.
