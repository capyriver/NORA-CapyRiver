# NORA 3.18 — контракт Cloudflare Code Mode

## Причина из реального журнала
Модель выдала несуществующий импорт `cloudflare/pages` и JS с неопределённой
переменной `pages`. MCP отвечает этими ошибками, а не отказом авторизации.
Описание runtime раньше находилось среди исторических tool exchanges; после
шести последних записей оно могло выпасть, при сохранённом флаге «схема известна».
В native JSON response_format передавалась inputSchema, но не JS globals/runtime.

## Исправление
- `CloudflareCodeMode` в AgentTask.cs и AgentLoop.cs: постоянный host guide;
  компактный вариант для контекста <=8192. Поля по реальному контракту MCP.
- Определение Code Mode по реальному tools/list: execute описывает
  cloudflare.request; search описывает spec.paths. Остальные серверы не затронуты.
- Перед публикацией: детерминированная ограниченная read-only проекция трёх путей
  Workers API через настоящий search. Сохранение результата до модели, обычная
  цепочка approval/ExecuteTool, отказ пользователя не обходится. Это не деплой.
- Результат каталога закреплён в инструкции; успешный checkpoint не повторяется.
- Локальное отклонение известных фантомных импортов `cloudflare/*`, без запуска
  удалённого execute. Не является общим JS анализатором или гарантией исправного
  произвольного кода. Результат проверки передаётся модели и виден в чате.
- Guide разделяет загрузку скрипта, включение маршрута и подтверждённую ссылку;
  запрещает выдумывать URL, аккаунт, SDK и подменять запрос unrelated Hello World.
- Защиты 3.17 остаются: failed/unknown/completed write replay и конечные бюджеты.

## Проверки
`Cloudflare318.log`: 31 проверка production loop: правильный probe до модели,
постоянные globals/каталог, локальная остановка импорта, переход к исправленному
вызову, удержание инструкции после >6 шагов, восстановление без повторного probe,
отказ пользователя, обычный диалог, несовместимые имена инструментов.
Остальные 980 проверок повторены; всего 1011. Детали в summary.json и логах.
Реальный MCP search выполнил тот же JS projection: получены методы/параметры
upload Worker, script subdomain, account subdomain. Это не изменяет аккаунт.

## Ограничения
Нет фактической проверки пользовательского Cloudflare write/OAuth/account setup,
генерации сайта вашей Qwen 7B или Windows GUI. Веса не обучались. Слабая модель
может ошибаться даже с правильным контрактом; код показывает реальную причину,
не обещает завершения любой задачи и не делает автоматическую публикацию
в другом аккаунте. Для проверки обновления — новый диалог, без воспроизведения
незавершённой записи вслепую. Архив исходников и журнал сборки включены.
